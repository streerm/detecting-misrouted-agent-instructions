Research Desk Wiring

One orchestrator, six specialist agents and eleven tool servers, drawn four ways. Solid boxes are built and tested. Dotted boxes are proposals and dashed amber boxes are missing pieces: neither is in the repo. Every box is used by at least one example, so the proposed and missing ones are shown as they would work if built, in dashed amber. The traces are scripted illustrations of how a request would travel. None is a recording of a real run, and results are described, never given as figures.

Read this as a buffet, not a build plan. It shows more components and wirings than a six-week project will use, so the team can choose. What is real today: seven agent cards, eleven tool servers that answer direct calls, and detectors that run offline. No request has been routed or answered by a real model, and no architecture on this page is fully implemented.
